# One-Star Review of Something Essential — make.fun entry

An entry for the make.fun competition **One-Star Review of Something
Essential**.

`main.ts` (Node 22, stdlib only) writes one single-line one-star review
to `$MAKEFUN_OUTPUT_DIR/entry.txt`: a deadpan complaint filed in earnest
against sleep, an everyday essential that cannot be fixed.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

The program validates length (159 of the 160-character cap) and
single-line shape before writing and produces byte-identical output on
every run.

The review: one star for sleep — eight hours offline nightly, no pause
button, unrequested dreams, and the customer still wakes up tired, as
if they had paid for the privilege.
